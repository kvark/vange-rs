# Design north star

**vange-rs** is a remake of *Vangers* (1998): same worlds, mechouses, and feel, rebuilt with modern Rust and GPU (wgpu).

Behavior and content stay aligned with the open-source original at [KranX/Vangers](https://github.com/KranX/Vangers). Prefer matching that tree (and the shipped data formats) over inventing parallel systems. New work should read as “the 1998 game, accelerated,” not a different game that happens to use the assets.

When unsure: check how Vangers does it, then port or approximate — don’t redesign the fantasy.
